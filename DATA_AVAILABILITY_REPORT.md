# SmartServe ML data availability audit

**Audit date:** 2026-10-30. Counts below are from project files and the configured local MongoDB database. Synthetic-demo files are reported separately and are never included in the existing production loaders or MongoDB collections.

## Feedback data

| Source | Records | Class / opinion distribution | Duplicates | Missing | Provenance |
|---|---:|---|---:|---:|---|
| `data/feedback_labels.csv` | 18 | positive 6, spice 6, quality 6 | 0 exact rows; 0 repeated comments | 0 | Hand-authored demonstration labels; not real student feedback |
| MongoDB `feedback` | 1 | opinion: disliked 1 | 0 in observed records | Relevant fields populated | Explicit `AUDIT -` / public feedback flow test record; not representative real-world training data |
| Synthetic demo generated | 150 | positive 50, spice 50, quality 50 | Generated separately; split records have unique IDs embedded in comment text | 0 by generator | Explicitly synthetic; 120 train and 30 eval, separate CSVs |

The 18 project feedback examples are balanced by class, but the dataset is too small and manually authored to represent real feedback or support reliable generalization claims. MongoDB's one feedback record is an audit test, not labeled training data.

## Demand data

| Source | Records | Coverage | Items | Provenance |
|---|---:|---|---:|---|
| `data/sample_data.csv` | 6 | 2026-10-20 to 2026-10-25 (6 consecutive dates) | 3 | Demonstration sample, not business transactions |
| MongoDB `orders` | 1 order; 1 completed | 2026-10-29 | 1 item, `AUDIT - Masala Tea` | Explicit audit checkout record; not representative daily sales |
| Synthetic demo generated | 270 daily item rows | 2026-08-02 to 2026-10-30 (90 days) | 3 | Explicitly synthetic; 72 train dates and 18 evaluation dates, separate CSVs |

The CSV has two rows per item, with four absent item-days per item in its six-day span. MongoDB has one completed test order on one date, so it cannot establish an item sales pattern. No cancelled/incomplete orders were counted in the completed-order count. Duplicate Mongo order IDs observed: zero. Quantities/items in the observed records are present.

## Synthetic demo files

Generated by `data/synthetic_demo/generate_demo_data.py` using seed `20261030`. Outputs are stored only under `data/synthetic_demo/`:

- `feedback_train.csv` (120 rows), `feedback_eval.csv` (30 rows)
- `sales_train.csv` (216 rows, 72 dates), `sales_eval.csv` (54 rows, 18 dates)
- `manifest.json` declares `source=synthetic_demo`, `is_synthetic=true`, seed, counts, and warning.

Synthetic values are for exercising code only. They must not be merged into MongoDB, the real feedback labels, or claimed as observed canteen performance. No model experiment was run on synthetic data for this audit.

## Conclusion and limitations

- **Real-world training-ready feedback:** 0 verified records. The one Mongo record is an audit test; the 18 CSV labels are hand-authored demos.
- **Real-world demand history:** 0 verified multi-day sales records. Mongo contains one completed audit order on one day; sample CSV rows are synthetic/demo.
- The available data does not support meaningful real-world model training, time-series validation, or performance claims. Collect consented, labeled feedback and genuine completed order line-items over many weeks/months, including zero-sales days, before evaluating forecasting models.
